---
title: ストレージ
description: CoreLayer が状態をどこに置き、SQLite・Supabase・PostgreSQL をどう切り替えるか。
---

CoreLayer は既定で状態をローカルに保存し、Supabase やセルフホスト PostgreSQL 上でも動作できます。ストレージモードは起動時に決まり、リクエスト単位では切り替わりません。

## ストレージモード

| モード | 値 | 説明 |
|--------|----|------|
| SQLite | `local`（既定） | 設定不要のローカルファイル DB |
| Supabase | `cloud` | あなた自身のクラウド PostgreSQL プロジェクト |
| PostgreSQL | `postgres` | セルフホスト PostgreSQL |

モードは独立したファイル `storage.json`（`config.json` と同じ設定ゾーン）に保存されます：

```json
{
  "storageMode": "local",
  "dbConfig": {
    "supabaseUrl": "https://your-project.supabase.co",
    "supabaseServiceKey": "…",
    "postgresUrl": "postgresql://user:pass@host:5432/corelayer"
  }
}
```

`dbConfig` は cloud と postgres モードでのみ必要です。PostgreSQL は環境変数 `DATABASE_URL` も受け付けます。

切り替えは **設定 → ストレージ** で行い、このファイルを書き込みます。新しいモードはデーモン**再起動後**に有効で、ライブなホットスワップではありません。

## ディスクレイアウト

ローカル状態は CoreLayer ホーム（`JARVIS_HOME` で上書き可能、デスクトップ既定は `~/.jarvis`）配下の 6 ゾーンに分かれます：

```text
~/.jarvis/
├── config/      config.json · routing.json          （秘密なし）
├── security/    credentials.json                     （POSIX で 0600）
├── memory/      USER.md · MEMORY.md · journal/ · dreams/
├── storage/     jarvis.db
├── worktrees/   active/ · snapshots/
└── cache/       symbol-graph/ · mcp-schemas/ · delegation-pipes/
```

資格情報は `security/credentials.json` から読みます。新しい場所が存在しない場合は旧 `config/credentials.json` も互換読み込みします。

sidecar モードではシェルが `JARVIS_APP_DATA_DIR`、`JARVIS_LOG_DIR`、`SQLITE_DB_PATH` でルートを上書きできます。

### 既知の例外

6 ゾーン構成ではなく旧位置から解決されるファイルが 2 つあります：

- `mcp-servers.json` は `~/.jarvis/config/mcp-servers.json` から読む
- SQLite のパスは app-paths の解決に従う（`SQLITE_DB_PATH` 未設定なら `data/jarvis.db`）

両者は新レイアウトの一部であるかのように黙って書かず、例外として明記します。

## スキーマ

データベースは Drizzle マイグレーションで管理されます。

| グループ | テーブル |
|---------|---------|
| 作業構造 | `workspaces`、`workspace_agents`、`projects`、`agent_profiles`、`tasks`、`artifacts`、`goals`、`plans` |
| 実行 | `agent_runs`、`agent_run_events`、`executor_runs`、`execution_logs`、`environment_sessions`、`environment_events` |
| ガバナンス | `approval_requests`、`permission_memories`、`capability_grants`、`pending_actions`、`tool_call_logs`、`audit_log`、`event_log` |
| 会話 | `conversations`、`messages` |
| 知識 | `memories`、`articles`、`reviews` |
| 設定 | `app_connections`、`model_profiles`、`scheduled_tasks` |
| チャネル | `channel_accounts`、`channel_conversations`、`channel_messages` |

## 選び方

- **SQLite** — 1 台、オフライン、最速。既定。
- **Supabase** — 複数デバイス、マネージドバックアップ。プロジェクトとポリシーは自分で管理。
- **PostgreSQL** — すでに DB を運用しており、第三者のコントロールプレーンを増やしたくない。

バックエンド間のバックグラウンド複製はありません。モードを切り替えると、デーモンは選んだバックエンドを読み書きします。
