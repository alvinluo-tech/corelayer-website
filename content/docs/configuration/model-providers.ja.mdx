すべてのモデル呼び出しは 1 つの OpenAI 互換アダプターを通ります。つまりプロバイダーは `baseURL` とキーであり、ベンダーごとの SDK ではありません。OpenAI のワイヤ形式を話すプロバイダーの追加はコードではなく設定です。

## 対応プロバイダー ID

以下の ID はプロバイダーリゾルバーが認識し、それぞれの環境変数と既定 base URL を持ちます：

| プロバイダー | ID | 既定 base URL |
|-------------|----|---------------|
| DeepSeek | `deepseek` | `https://api.deepseek.com/v1` |
| OpenAI | `openai` | `https://api.openai.com/v1` |
| Anthropic | `anthropic` | `https://api.anthropic.com/v1` |
| Google Gemini | `gemini` | `https://generativelanguage.googleapis.com/v1beta/openai` |
| Groq | `groq` | `https://api.groq.com/openai/v1` |
| OpenRouter | `openrouter` | `https://openrouter.ai/api/v1` |
| MiMo（Xiaomi） | `mimo` | `https://token-plan-ams.xiaomimimo.com/v1` |
| Qwen（Alibaba） | `qwen` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Ollama | `ollama` | `http://localhost:11434/v1` |

Gemini の ID は `gemini` で、`google` ではありません。後者は環境変数名 `GOOGLE_API_KEY` にのみ現れます。

## 設定の場所

| ファイル | 内容 |
|---------|------|
| `~/.jarvis/config/config.json` | `providers[]`、`activeProvider`、`activeModel`、ルーティング規則、既定値 |
| `~/.jarvis/security/credentials.json` | API キー（プロバイダー id ごと） |

API キーが `config.json` に書かれることはありません。

```json
{
  "version": 1,
  "activeProvider": "mimo",
  "activeModel": "mimo-v2.5-pro",
  "providers": [
    {
      "id": "deepseek",
      "name": "DeepSeek",
      "type": "openai_compatible",
      "baseURL": "https://api.deepseek.com/v1",
      "enabled": true
    }
  ]
}
```

`type` はリモートプロバイダーでは `openai_compatible`、ローカルサーバーでは `ollama` です。

## キーと base URL の解決順

プロバイダーについて、リゾルバーは次の順で確認します：

1. `security/credentials.json` と `config.json` のプロバイダー項目
2. プロバイダーの環境変数（例：`DEEPSEEK_API_KEY`、`ANTHROPIC_AUTH_TOKEN`）
3. 組み込みの既定 base URL

URL がプロバイダー名として認識されない場合、リゾルバーはホスト名から推測します（例：`api.deepseek.com` → `deepseek`）。

環境変数の完全な表は [設定ファイル](/docs/reference/config-file#environment-variables) を参照。

## ルーティングとフォールバック

- `activeProvider` / `activeModel` が既定のターゲット。
- `routingRules[]` は `taskType` を `modelId` にマップし、任意の `conditions` を持てます。
- プロバイダーが繰り返し失敗すると「デッド」とされクールダウンします（2 回連続失敗、以降は指数バックオフ）。以後の呼び出しは同じタイムアウトを払わずにスキップします。成功でリセット。

## モデルファミリー

アダプターはファミリーごとに小さな調整を行い、設定項目として露出しません：

- 推論モデル（`o1`…`o4` とプレビュー）はそれらのエンドポイントが受け付けるパラメータを使う
- Anthropic モデルは OpenAI 互換エンドポイント経由で呼ばれ、ツール呼び出しとストリーミングは他と同様に振る舞う

## 「現在のモデル」について

本ページは意図的にモデル名を列挙しません。モデル ID の変化は文書より速いためです。**設定 → モデル**（プロバイダーがモデル一覧を公開している場合はそれを読む）か、プロバイダーの公式ドキュメントを使ってください。ここに名前を固定すると、1 リリースで古くなります。
