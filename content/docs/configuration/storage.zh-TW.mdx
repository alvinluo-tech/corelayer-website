---

CoreLayer 預設把狀態存在本機，也可以改為執行在 Supabase 或自架 PostgreSQL 上。儲存模式在啟動時確定，不按請求切換。

## 儲存模式

| 模式 | 取值 | 說明 |
|------|------|------|
| SQLite | `local`（預設） | 零設定的本機檔案資料庫 |
| Supabase | `cloud` | 你自己的雲端 PostgreSQL 專案 |
| PostgreSQL | `postgres` | 自架 PostgreSQL |

模式存放在獨立檔案 `storage.json` 中（與 `config.json` 同在設定分區）：

```json
{
  "storageMode": "local",
  "dbConfig": {
    "supabaseUrl": "https://your-project.supabase.co",
    "supabaseServiceKey": "…",
    "postgresUrl": "postgresql://user:pass@host:5432/corelayer"
  }
}
```

`dbConfig` 僅在 cloud 與 postgres 模式下需要。PostgreSQL 也支援環境變數 `DATABASE_URL`。

切換在 **設定 → 儲存** 中完成，它會寫入該檔案。新模式由守護行程**重啟後**生效，並非線上熱切換。

## 磁碟配置

本機狀態分布在 CoreLayer 主目錄（可用 `JARVIS_HOME` 覆寫；桌面預設 `~/.jarvis`）下的六個分區：

```text
~/.jarvis/
├── config/      config.json · routing.json          （無密鑰）
├── security/    credentials.json                     （POSIX 下 0600）
├── memory/      USER.md · MEMORY.md · journal/ · dreams/
├── storage/     jarvis.db
├── worktrees/   active/ · snapshots/
└── cache/       symbol-graph/ · mcp-schemas/ · delegation-pipes/
```

憑證從 `security/credentials.json` 讀取；當新位置不存在時，仍相容舊的 `config/credentials.json`。

在 sidecar 模式下，外殼可透過 `JARVIS_APP_DATA_DIR`、`JARVIS_LOG_DIR` 與 `SQLITE_DB_PATH` 覆寫根目錄。

### 已知例外

有兩個檔案仍然解析到舊位置，而非六分區配置：

- `mcp-servers.json` 從 `~/.jarvis/config/mcp-servers.json` 讀取
- SQLite 路徑沿用 app-paths 的解析結果（除非設定 `SQLITE_DB_PATH`，否則為 `data/jarvis.db`）

這裡把兩者作為例外寫明，而不是悄悄描述成新配置的一部分。

## 資料結構

資料庫由 Drizzle 遷移管理。

| 分組 | 表 |
|------|----|
| 工作結構 | `workspaces`、`workspace_agents`、`projects`、`agent_profiles`、`tasks`、`artifacts`、`goals`、`plans` |
| 執行 | `agent_runs`、`agent_run_events`、`executor_runs`、`execution_logs`、`environment_sessions`、`environment_events` |
| 治理 | `approval_requests`、`permission_memories`、`capability_grants`、`pending_actions`、`tool_call_logs`、`audit_log`、`event_log` |
| 對話 | `conversations`、`messages` |
| 知識 | `memories`、`articles`、`reviews` |
| 設定 | `app_connections`、`model_profiles`、`scheduled_tasks` |
| 頻道 | `channel_accounts`、`channel_conversations`、`channel_messages` |

## 如何選擇

- **SQLite** — 單機、離線、查詢最快。預設。
- **Supabase** — 多裝置，並希望託管備份；專案與策略由你掌控。
- **PostgreSQL** — 你已維運資料庫，不想引入第三方控制面。

後端之間沒有背景複寫：切換模式即意味著守護行程讀寫你選定的後端。
