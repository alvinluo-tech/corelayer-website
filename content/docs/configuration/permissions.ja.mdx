title: 権限
description: パーミッションガードのリスクポリシーとアプリ単位の上書きを設定します。
---

パーミッションガードはツール呼び出しごとに、実行する・通知する・尋ねる・拒否するのいずれかを決めます。決定はツールの宣言リスクとポリシーの純粋な関数です。

## リスク → アクション

| リスク | 既定アクション |
|--------|----------------|
| `low` | `auto` — 静かに実行 |
| `medium` | `notify` — 実行して通知 |
| `high` | `confirm` — 決定まで停止 |
| `critical` | `deny` — 拒否 |

## 既定ポリシー

```ts
defaultPolicy: {
  low: "auto",
  medium: "notify",
  high: "confirm",
  critical: "deny",
}
```

これがデーモンが実際に使うポリシーで、マッピングは `@jarvis/permission-guard` に定義され、すべてのツール呼び出しに適用されます。

**まだユーザー設定できません。** ガードは既定値で構築され、`config.json` に権限セクションはありません。本ファイルの過去版が説明していた `permissions.rules` 配列は存在せず、書いても効果がありません。

## アプリ単位の上書き

ガードの設定構造はアプリ単位の上書きをサポートします：

```ts
appPermissions: {
  "filesystem": { write: true,  execute: false },
  "untrusted-mcp": { write: false, execute: false },
}
```

各フラグの対応：

| リスク | `write: true` | `write: false` |
|--------|---------------|----------------|
| `medium` | `notify` | `confirm` |
| `high` | `confirm` | `deny` |

| リスク | `execute: true` | `execute: false` |
|--------|-----------------|------------------|
| `critical` | `confirm` | `deny` |

`low` は常に `auto`。

上書きは存在すれば評価されますが、デーモンには現在それをディスクから読むコードがないため、上書き付きでガードを構築する呼び出し元にのみ作用します。

## 音声モード

音声実行はリスクに関係なく厳格です：読み取り専用は自動承認、それ以外は確認が必要。音声での要求はタイプ入力より誤発火しやすいためです。

## 承認リクエスト

アクションが `confirm` のとき、ガードは決定をメモリに置きません：

1. `approval_request` を永続化（アクションダイジェスト、リスク、範囲、期限）
2. 実行を停止
3. UI がリクエストを表示 — 承認、拒否、記憶
4. 決定後に実行を再開または失敗させる

エンドポイント：

```text
GET  /api/approvals
GET  /api/approvals/:id
POST /api/approvals/:id/approve
POST /api/approvals/:id/deny
POST /api/approvals/:id/remember
POST /api/approvals/batch/approve
POST /api/approvals/batch/deny
POST /api/approvals/expire-stale
```

「期限切れ」は実在する状態です。無人キューには誰も答えないリクエストが溜まり、`expire-stale` が実行を永久に停止させずに閉じます。

## 権限メモリ

「記憶」は決定をアクションダイジェストに対して保存します。ツール名ではなく具体的なアクションです。同じアクションは二度尋ねず、異なるパス・コマンド・パラメータ集合は別ダイジェストとして再度尋ねます。

## 監査

決定はすべて `audit_log` に書かれ、照会できます：

```text
GET /api/audit?actor=jarvis&action=tool.execute&riskLevel=high&since=2026-10-01T00:00:00Z&limit=50
```

エントリには `actor`、`action`、`resource`、`riskLevel`、`permissionDecision`、`confirmedByUser`、`result`、`metadata`、`createdAt` が含まれます。
