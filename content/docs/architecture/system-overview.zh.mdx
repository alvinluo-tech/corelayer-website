CoreLayer 是一个本地优先的桌面 **Agent OS**。Tauri 外壳承载界面并监管 Node.js 守护进程；守护进程拥有全部运行时、全部工具调用以及全部持久化状态。

本页描述的是**当前实际运行的系统**。长期方向请见 [多运行时演进方向](/docs/architecture/multi-runtime-direction)。

## 拓扑

```text
┌──────────────────────────────────────────────────────────────┐
│ Tauri 桌面外壳（Rust）                                        │
│   ├─ Webview UI（React 19 + Vite + Tailwind）                │
│   ├─ 守护进程监管：spawn / 健康检查 / 重启 / 关闭              │
│   └─ HTTP 代理 → 本机守护进程                                 │
└───────────────────────────┬──────────────────────────────────┘
                            │ HTTP（仅回环，默认 3001）
┌───────────────────────────┴──────────────────────────────────┐
│ Node.js 守护进程（TypeScript + Hono）                         │
│                                                              │
│  运行时宿主（注册 · 生命周期 · 状态）                          │
│   ├─ agent        — 会话循环与工具调用                        │
│   ├─ tool         — 注册中心、路由、原生工具                  │
│   ├─ coding       — 执行器适配器、worktree、质量门禁          │
│   ├─ memory       — 长期记忆与快照                            │
│   ├─ voice        — 唤醒词、ASR、TTS、打断续听                │
│   └─ scheduler    — 定时触发的自治任务                        │
│                                                              │
│  工作流平面                                                   │
│   ├─ run dispatcher / queue / slot manager                   │
│   ├─ delegation（单调收窄）                                   │
│   ├─ task graph DAG 执行器                                    │
│   └─ adjudication（对抗式仲裁）                               │
│                                                              │
│  横切能力                                                     │
│   ├─ 权限守卫 + 审批（HITL）                                  │
│   ├─ 审计日志 + 事件日志                                      │
│   └─ 持久化（默认 SQLite；可选 Supabase / PostgreSQL）        │
└──────────────────────────────────────────────────────────────┘
```

## 分层职责

### 前端（React）

渲染会话、工作空间、运行实例、审批与设置。只通过 Tauri 桥接访问守护进程，自身不打开数据库，也不直连模型供应商。

### Tauri 桥接层（Rust）

负责启动与监管守护进程 sidecar、转发 HTTP 调用、提供原生能力（路径、窗口、托盘）。所有 IPC 命令都显式注册。

### 守护进程（Node.js）

唯一拥有权限的组件。它持有运行时注册表、组装上下文、经模型网关调用模型、在权限守卫之后执行工具，并通过仓储层持久化。

### 共享包

守护进程组合八个 workspace 包，而不是复制其逻辑：

| 包 | 职责 |
|----|------|
| `@jarvis/types` | 共享 TypeScript 类型 |
| `@jarvis/model-gateway` | 供应商解析与模型路由 |
| `@jarvis/mcp-client` | MCP 连接（stdio、HTTP、SSE） |
| `@jarvis/tool-registry` | 工具目录与解析 |
| `@jarvis/permission-guard` | 风险分类、策略、审计 |
| `@jarvis/runtime-core` | 运行时生命周期原语 |
| `@jarvis/runtime-protocol` | 运行时协议定义 |
| `@jarvis/execution-environment` | 执行抽象（基于 worktree） |

## 实际注册了哪些运行时

注册代码位于 `daemon/src/runtimes/index.ts`。已注册到运行时宿主、并通过 `GET /api/runtime/components` 上报状态的共有六个：

`agent`、`tool`、`coding`、`memory`、`voice`、`scheduler`。

**computer-control 未注册。** 它的风险、权限、审计层都已存在，工具也已定义，但执行路径仍直接返回成功而未真正操作操作系统，也没有 Rust 侧能力支撑。注册它会让系统对外宣称一个“运行中却什么都不做”的运行时，因此在真实实现落地前保持不注册。任何文档（包括本文件的历史版本）若把它列为可用运行时，都是错误的。

## 通信

```text
用户输入
  → React 前端
  → Tauri IPC
  → Rust 守护进程监管（HTTP 代理）
  → Hono 路由（/api/conversations/:id/messages/stream、/api/chat/stream 等）
  → agent 运行时：上下文组装 → 模型 → 工具调用 → 完成策略
  → 沿同一路径以 SSE / JSON 返回
```

长任务不会阻塞一次对话：run dispatcher 会持久化 `agent_run`，队列为其占用槽位，进度写入事件日志。客户端通过 `GET /api/events` 与 `GET /api/runs/:id/events` 读取。
