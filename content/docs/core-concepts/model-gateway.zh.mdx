---
title: 模型网关
description: CoreLayer 如何把供应商 id 变成一次流式模型调用。
---

模型网关是一次 Agent 轮次通往模型的唯一路径。它解析当前供应商、按模型族适配请求、流式返回，并在供应商不健康时降级。

## 路径

```text
Agent 轮次
  → activeProvider / activeModel（或命中路由规则）
  → resolveProvider(id)：配置 → 凭据 → 环境变量 → 默认 base URL
  → OpenAI 兼容客户端（Vercel AI SDK v6）
  → 模型族适配（推理模型、Anthropic）
  → 流式调用
  → 文本增量与工具调用回到循环
```

## 一个适配器，多家供应商

所有远程供应商都通过同一个 OpenAI 兼容适配器调用。这正是供应商可互换的原因：供应商就是一个 base URL 加一个密钥，它的模型列表是数据而不是代码分支。

## 循环控制

Agent 循环是 Vercel AI SDK 的核心循环，而不是手写 `while`：

- `prepareStep` 逐步决定可用工具以及本轮是否继续
- 熔断器（重复相同调用、无进展检测）与步数预算（`defaults.maxSteps`，上限 100）约束本轮
- 超时：每次调用 `streamTimeout`，每轮 `turnTimeout`

向手写循环注入中途消息的机制已移除；`POST /api/runs/:id/message` 返回 `410`。

## 流式

响应默认流式：

- 文本随生成逐段出现
- TTS 可按句播报
- 工具调用在步骤产出时立即执行

## 健康与降级

连续失败两次的供应商进入 20 秒冷却，重复失败时指数退避。冷却期间调用会跳过它，而不是再等一次同样的超时。首次成功即重置计数。

## 成本统计

供应商报告用量时才会记录 token。经 ACP 驱动的执行器无法计量（协议没有用量更新），因此这些运行的成本数字明确标注为估算值，而非供应商标称计数。
