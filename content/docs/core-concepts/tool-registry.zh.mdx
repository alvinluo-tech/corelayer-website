---
title: 工具注册
description: 原生工具、MCP 工具与动态发现的工具如何到达模型。
---

工具注册中心是每次工具调用的解析入口。它汇总原生工具与 MCP 提供的工具，也是工具风险等级被声明的地方。

## 来源

| 来源 | 说明 | ID 形式 |
|------|------|---------|
| **原生** | 在 tool 运行时中实现的工具 | `native:<name>` |
| **MCP** | 已连接 MCP 服务器上报的工具 | `mcp:<serverId>:<toolName>` |

## 风险靠声明，而非推断

每个原生工具注册时必须显式给出风险等级：

```ts
registerTool("dispatch_agent", tool({ ... }), "high");
```

这是一条刻意的约束。曾经用工具名推断风险，结果 `dispatch_agent` 与 `run_task_graph` 因为名字里没有危险词被判为 `low`——而它们都会派生写入文件、执行命令的运行，而 `low` 默认自动放行。名字不是效果的证据。

## 核心工具与按需发现

每轮都暴露全部工具 schema 会消耗上下文并降低工具选择质量。因此路由分两层：

1. **核心工具** 始终可用。
2. **其余工具** 通过 `search_tools` 按查询匹配完整目录并返回匹配项的 schema。模型用找到的工具做计划，而不是背着整个目录。

## 内建原生工具

| 工具 | 风险 | 用途 |
|------|------|------|
| `get_code_skeleton` | `low` | 文件或符号的 AST 剪枝骨架——保留签名与类型，折叠函数体 |
| `search_tools` | `low` | 发现核心集之外的工具 |
| `listConversations` | `low` | 列出会话 |
| `previewConversationCleanup` | `low` | 清理查询的试运行 |
| `taskflow_create_task` | `medium` | 创建任务 |
| `taskflow_list_tasks` | `low` | 列出任务 |
| `deleteConversation` | `high` | 删除单个会话 |
| `deleteConversationsByQuery` | `high` | 按查询批量删除 |
| `requestConversationCleanup` | `high` | 经审批的清理 |
| `dispatch_agent` | `high` | 向子 Agent 委派一次受限运行 |
| `run_task_graph` | `high` | 执行编码子任务 DAG |
| `createTask` / `updateTask` | `medium` | 任务管理 |
| `getTodayTasks` / `queryTasks` | `low` | 查询任务 |
| `deleteTask` | `high` | 删除任务 |
| `addArticle` / `updateReadingStatus` | `medium` | 阅读清单 |
| `getReadingList` / `getReadingStats` / `recommendNext` | `low` | 阅读查询 |
| `getDailySummary` / `getWeeklyStats` / `getReviewHistory` | `low` | 回顾查询 |
| `saveReview` | `medium` | 保存回顾 |
| `memory_store` | `medium` | 写入长期记忆（会持续影响后续提示，故非 `low`） |
| `memory_search` / `memory_list` | `low` | 读取记忆 |
| `memory_delete` | `high` | 删除记忆 |

所有原生工具都在注册时声明风险，不依赖名称或参数推断。

MCP 工具携带服务器配置的风险策略（`riskPolicy` 按等级），并在连接时注册。

## 解析

```text
模型请求工具 "search_tools"
  → 注册中心解析 native:search_tools
  → 权限守卫读取声明的风险
  → 策略判定 auto / notify / confirm / deny
  → 执行、审计、返回
```

解析同时接受裸名称与 `native:` 前缀，因此模型无需了解命名空间。

## 查看注册中心

- `GET /api/tools` — 列出已注册工具
- `GET /api/tools/:id` — 单个工具
- `POST /api/tools/filter` — 按来源或风险筛选
- `POST /api/tools/:id/execute` — 直接执行（仍经过权限检查）
- `GET /api/tools/logs` — 最近的调用日志
