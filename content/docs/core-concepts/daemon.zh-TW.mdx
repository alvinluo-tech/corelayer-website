守護行程是一個在背景執行的 Node.js 行程（TypeScript + Hono HTTP），擁有全部權限。Tauri 外殼監管它；除此之外任何元件都不得直連模型供應商、資料庫或執行器。

## 結構

```text
Tauri 桌面外殼（Rust）
  └─ 守護行程監管（啟動 · 健康 · 重啟 · 終止）
     └─ Node.js 守護行程（Hono，回環 HTTP）
        ├─ 執行階段宿主        agent · tool · coding · memory · voice · scheduler
        ├─ 工作流平面        dispatcher · queue · slots · delegation · DAG · judge
        ├─ 權限守護          風險 → 策略 → 核准 → 稽核
        ├─ MCP 用戶端        stdio / HTTP / SSE 伺服器
        └─ 持久化            SQLite（預設）· Supabase · PostgreSQL
```

## 監管行程

Rust 側負責：

- 應用啟動時拉起守護行程 sidecar
- 健康檢查並在崩潰時重啟
- 透過環境變數傳入路徑與連接埠
- 結束時終止守護行程

執行狀態透過 `GET /api/runtime/status`（pid、執行時長、記憶體、儲存模式、路徑、各執行階段健康）與 `GET /api/runtime/components` 暴露給介面。

## HTTP 介面

守護行程監聽回環，預設連接埠 `3001`。路由群組在 `daemon/src/bootstrap/register-routes.ts` 中掛載：

`/api/chat` · `/api/conversations` · `/api/tasks` · `/api/articles` · `/api/reviews` · `/api/settings` · `/api/voice` · `/api/mcp` · `/api/tools` · `/api/tasks/scheduled` · `/api/approvals` · `/api/workspaces` · `/api/projects` · `/api/runs` · `/api/runtimes` · `/api/runtime/queue` · `/api/memories` · `/api/agent-profiles` · `/api/events` · `/api/audit` · `/api/runtime` · `/api/agent-broker`

重要端點見 [API 參考](/docs/reference/api-endpoints)。

## 開發與生產

| 模式 | 執行方式 |
|------|----------|
| 開發 | `pnpm dev:daemon` — `tsx watch` 變更即重啟 |
| 生產 | `pnpm build:daemon:sidecar` — 打包為 SEA 二進位，由外殼拉起 |

## 狀態

除持久化的內容外，守護行程在重啟之間是無狀態的。長任務以執行記錄與佇列項目持久化，待定核准也會落庫，因此重啟是「續上」而不是「遺忘」。
