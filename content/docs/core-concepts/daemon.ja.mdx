---
title: デーモン
description: すべてのランタイム、ツール呼び出し、状態を所有する Node.js プロセス。
---

デーモンはバックグラウンドで動く Node.js プロセス（TypeScript + Hono HTTP）で、すべての権限を持ちます。Tauri シェルが監督し、それ以外の何もプロバイダー、データベース、エグゼキューターへ直接接続してはなりません。

## 構成

```text
Tauri デスクトップシェル（Rust）
  └─ デーモン監督（起動 · ヘルス · 再起動 · 停止）
     └─ Node.js デーモン（Hono、ループバック HTTP）
        ├─ ランタイムホスト        agent · tool · coding · memory · voice · scheduler
        ├─ ワークフロー面          dispatcher · queue · slots · delegation · DAG · judge
        ├─ パーミッションガード    リスク → ポリシー → 承認 → 監査
        ├─ MCP クライアント        stdio / HTTP / SSE サーバー
        └─ 永続化                SQLite（既定）· Supabase · PostgreSQL
```

## 監督プロセス

Rust 側が行うこと：

- アプリ起動時にデーモン sidecar を起動
- ヘルスチェックとクラッシュ時の再起動
- 環境変数でパスとポートを渡す
- 終了時にデーモンを停止

実行状態は `GET /api/runtime/status`（pid、稼働時間、メモリ、ストレージモード、パス、ランタイム別の健康）と `GET /api/runtime/components` で UI に公開されます。

## HTTP 面

デーモンはループバック、既定ポート `3001` で待ち受けます。ルートグループは `daemon/src/bootstrap/register-routes.ts` でマウントされます：

`/api/chat` · `/api/conversations` · `/api/tasks` · `/api/articles` · `/api/reviews` · `/api/settings` · `/api/voice` · `/api/mcp` · `/api/tools` · `/api/tasks/scheduled` · `/api/approvals` · `/api/workspaces` · `/api/projects` · `/api/runs` · `/api/runtimes` · `/api/runtime/queue` · `/api/memories` · `/api/agent-profiles` · `/api/events` · `/api/audit` · `/api/runtime` · `/api/agent-broker`

主要エンドポイントは [API リファレンス](/docs/reference/api-endpoints) を参照。

## 開発と本番

| モード | 実行方法 |
|--------|---------|
| 開発 | `pnpm dev:daemon` — `tsx watch` で変更時に再起動 |
| 本番 | `pnpm build:daemon:sidecar` — SEA バイナリに固めてシェルが起動 |

## 状態

永続化された内容を除き、デーモンは再起動間で無状態です。長時間作業は実行レコードとキュー項目として永続化され、保留中の承認も保存されるため、再起動は「忘れる」ではなく「続きから」です。
