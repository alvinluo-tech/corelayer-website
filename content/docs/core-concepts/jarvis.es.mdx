title: Asistente IA Jarvis
description: La persona del asistente que planifica, delega y responde por el trabajo que CoreLayer ejecuta.
---

Jarvis es la persona del asistente integrada. No es un servicio aparte: es el bucle de conversacion del runtime agent junto con el prompt de sistema, las herramientas y la gobernanza que lo rodean. Coordina trabajo; no salta el sistema de permisos para hacerlo.

## Como funciona un turno

```text
Entrada (texto o transcripcion de voz)
  → ensamblado de contexto
      historial de conversacion (con ramas)
      memoria de largo plazo (snapshot de MEMORY.md / USER.md + memorias recuperadas)
      herramientas core + herramientas on-demand elegidas por el router
  → el Model Gateway resuelve proveedor y modelo activos
  → bucle de Vercel AI SDK v6; el control de pasos vive en prepareStep
  → las tool calls pasan por el Permission Guard
  → loop breakers, presupuesto de pasos y timeout de turno acotan el turno
  → la politica de completion y los quality gates deciden si entregar
```

## Que puede hacer

| Capacidad | Notas |
|-----------|-------|
| Conversacion y tool calling | Herramientas nativas, MCP y descubiertas |
| Trabajo de larga duracion | Despacha una ejecucion; sobrevive al turno y se cancela por id |
| Delegacion de codigo | Entrega la tarea a un ejecutor externo gestionado dentro de un worktree |
| Task graphs | DAG declarativo de subtareas; los nodos independientes corren en paralelo |
| Memoria | Memoria persistente mas un snapshot congelado inyectado por turno |
| Voz | Wake word, ASR en streaming, TTS por oracion, barge-in |
| Planificacion | Ejecuciones autonomas disparadas por cron |

## Memoria

La memoria esta estratificada en lugar de ser un unico historial:

- **Memoria Markdown explicita** — `USER.md` y `MEMORY.md` en la zona de memoria, legibles y editables por ti
- **Memorias recuperadas** — entradas puntuadas contra el turno actual, por encima de un minimo configurable (`defaults.memoryMinScore`)
- **Snapshot congelado** — la memoria inyectada se congela por ejecucion, asi un turno no ve memoria escrita despues de empezar
- **Seguimiento de inyeccion** — cada memoria registra cuando se inyecto por ultima vez, para que las frecuentes no se reinyecten sin fin

## Delegacion

Jarvis puede entregar una tarea a una ejecucion hija, pero los limites solo pueden estrecharse: las rutas se intersectan, las herramientas se intersectan, las comprobaciones requeridas se suman y el ejecutor y el modelo quedan fijos. Ver [Gobernanza de Ejecutores](/docs/architecture/executor-governance).

## Restricciones de honestidad

- A Jarvis se le indica tratar la salida de herramientas como dato, no como instruccion.
- Una finalizacion solo se entrega cuando la evidencia configurada (tests, artefactos, alcance) la sostiene.
- Cuando el juez adversarial esta activo y rechaza un diff, el intento se reintenta dentro de `adjudication.maxRetries` y luego falla en lugar de reportarse como exito.
