---
title: CLI 命令
description: CoreLayer 仓库中的包脚本与辅助命令。
---

CoreLayer 由 pnpm workspace 脚本驱动。除特别说明外，命令均在仓库根目录执行。

## 开发

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 守护进程 + Tauri 应用同时启动（concurrently） |
| `pnpm dev:daemon` | 仅守护进程，`tsx watch` 热重载 |
| `pnpm dev:frontend` | 仅 Tauri 应用 |
| `pnpm dev:web` | 浏览器模式前端，不带 Tauri 外壳 |

## 构建

| 命令 | 说明 |
|------|------|
| `pnpm build` | 先构建 sidecar，再构建 Tauri 应用 |
| `pnpm build:daemon` | 守护进程 TypeScript 构建 |
| `pnpm build:daemon:sidecar` | 将守护进程打包为 sidecar 可执行文件 |

## 质量

| 命令 | 说明 |
|------|------|
| `pnpm lint` / `pnpm lint:fix` | 覆盖前端、守护进程与包的 ESLint |
| `pnpm format` / `pnpm format:check` | Prettier |
| `pnpm test` | 所有包的 Vitest |
| `pnpm typecheck` | 所有包的 TypeScript 检查 |

`pnpm test` 不包含可靠性评测——那会消耗真实模型调用，需要显式执行（见下文）。

## 验证与打包

| 命令 | 说明 |
|------|------|
| `pnpm test:smoke:sidecar` | 对构建好的 sidecar 做冒烟测试 |
| `pnpm clean` | 清理各包构建产物 |
| `pnpm clean:app` | 结束正在运行的应用进程 |
| `pnpm clean:daemon` | 结束占用 3001 端口的进程 |
| `pnpm clean:all` | 以上两者 |
| `pnpm clean:sea` | 删除单可执行文件构建的临时目录 |

## 发布

| 命令 | 说明 |
|------|------|
| `pnpm release` | standard-version patch 发布 |
| `pnpm release:minor` | minor 发布 |
| `pnpm release:major` | major 发布 |
| `pnpm commitlint` | 校验最近一条提交信息 |

## 可靠性评测

在 `daemon/` 下运行：

```powershell
npx tsx src/eval/cli.ts --corpus src/eval/corpora/core.json --k 3
npx tsx src/eval/cli.ts --corpus src/eval/corpora/holdout.json --k 3 --compare JARVIS_REFLECTION=1
```

需要 `ANTHROPIC_MODEL`、`ANTHROPIC_BASE_URL` 与 `ANTHROPIC_AUTH_TOKEN` 指向健康的网关。详见 [运行可靠性评测](/docs/guides/run-reliability-eval)。

## 数据库

在 `daemon/` 下运行：

| 命令 | 说明 |
|------|------|
| `pnpm db:generate` | 生成迁移并编译 |
| `pnpm db:migrate` | 应用迁移 |
| `pnpm db:studio` | 打开 Drizzle Studio |
