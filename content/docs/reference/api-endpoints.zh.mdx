---
title: API 端点参考
description: 守护进程 HTTP API，按资源分组。
---

守护进程暴露回环 HTTP API（默认 `127.0.0.1:3001`，可用 `DAEMON_HOST` / `DAEMON_PORT` 覆盖）。Tauri 界面经外壳代理访问它；工具和脚本可在同一台机器上直接调用。

响应为 JSON。按路由不同，集合的包装形式为 `{ "data": [...] }` 或 `{ "entries": [...], "total": n, "count": n }`。

## 健康与运行时

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/health`、`/health` | `{ status, timestamp, storageMode, aiProvider, aiModel }` |
| GET | `/api/runtime/status` | pid、运行时长、内存、存储模式、路径、各运行时健康 |
| GET | `/api/runtime/components` | 已注册运行时组件与状态 |
| POST | `/api/runtime/shutdown` | 停止守护进程（仅回环对端） |
| GET | `/api/runtime/queue` · `/status` · `/resources` | 队列深度、槽位状态、资源用量 |
| GET | `/api/runtimes/coding/diagnostics` | 编码执行器诊断 |
| POST | `/api/runtimes/coding/:id/dry-run` | 执行器试运行 |

## 审批

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/approvals` | 待定与最近 |
| GET | `/api/approvals/:id` | 单个请求 |
| POST | `/api/approvals/:id/approve` | 批准并恢复 |
| POST | `/api/approvals/:id/deny` | 拒绝并终止运行 |
| POST | `/api/approvals/:id/remember` | 批准并写入权限记忆 |
| POST | `/api/approvals/batch/approve` · `/batch/deny` | 批量决定 |
| POST | `/api/approvals/expire-stale` | 关闭无人应答的请求 |

不存在 `/api/permissions/*` 分组。审批与审计是彼此独立的资源。

## 鉴权

不需要 token：API 绑定在回环地址，不暴露到网络。`/api/runtime/shutdown` 还会校验对端地址是回环。
