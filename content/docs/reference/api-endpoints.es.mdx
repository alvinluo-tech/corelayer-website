---
title: Referencia de Endpoints API
description: La API HTTP del daemon, agrupada por recurso.
---

El daemon expone una API HTTP en loopback (`127.0.0.1:3001` por defecto; `DAEMON_HOST` / `DAEMON_PORT` para cambiarlo). La UI de Tauri llega por el proxy del shell; las herramientas y scripts pueden llamarla directamente desde la misma maquina.

Las respuestas son JSON. Segun la ruta, las colecciones se envuelven como `{ "data": [...] }` o `{ "entries": [...], "total": n, "count": n }`.

## Salud y runtimes

| Metodo | Ruta | Proposito |
|--------|------|-----------|
| GET | `/api/health`, `/health` | `{ status, timestamp, storageMode, aiProvider, aiModel }` |
| GET | `/api/runtime/status` | pid, uptime, memoria, modo de almacenamiento, rutas, salud por runtime |
| GET | `/api/runtime/components` | Componentes de runtime registrados y su estado |
| POST | `/api/runtime/shutdown` | Detener el daemon (solo peers loopback) |
| GET | `/api/runtime/queue` · `/status` · `/resources` | Profundidad de cola, estado de slots, uso de recursos |
| GET | `/api/runtimes/coding/diagnostics` | Diagnostico de ejecutores de codigo |
| POST | `/api/runtimes/coding/:id/dry-run` | Dry-run de un ejecutor |

## Autenticacion

No se requiere token: la API esta ligada a loopback y no se expone a la red. `/api/runtime/shutdown` ademas verifica que la direccion del peer sea loopback.
