---

CoreLayer is driven by pnpm workspace scripts. All commands run from the repository root unless noted.

## Development

| Command | Description |
|---------|-------------|
| `pnpm dev` | Daemon + Tauri app together (concurrently) |
| `pnpm dev:daemon` | Daemon only, with `tsx watch` hot reload |
| `pnpm dev:frontend` | Tauri app only |
| `pnpm dev:web` | Frontend in browser mode, no Tauri shell |

## Build

| Command | Description |
|---------|-------------|
| `pnpm build` | Sidecar binary, then the Tauri app |
| `pnpm build:daemon` | TypeScript build of the daemon |
| `pnpm build:daemon:sidecar` | Package the daemon as a sidecar executable |

## Quality

| Command | Description |
|---------|-------------|
| `pnpm lint` / `pnpm lint:fix` | ESLint across frontend, daemon, and packages |
| `pnpm format` / `pnpm format:check` | Prettier |
| `pnpm test` | Vitest across all packages |
| `pnpm typecheck` | TypeScript across all packages |

`pnpm test` does not run the reliability eval — that costs real model turns and is invoked explicitly (see below).

## Verification and packaging

| Command | Description |
|---------|-------------|
| `pnpm test:smoke:sidecar` | Smoke-test the built sidecar |
| `pnpm clean` | Clean build outputs in all packages |
| `pnpm clean:app` | Kill a running app process |
| `pnpm clean:daemon` | Kill whatever holds port 3001 |
| `pnpm clean:all` | Both of the above |
| `pnpm clean:sea` | Remove the single-executable build temp directory |

## Release

| Command | Description |
|---------|-------------|
| `pnpm release` | Standard-version patch release |
| `pnpm release:minor` | Minor release |
| `pnpm release:major` | Major release |
| `pnpm commitlint` | Validate the last commit message |

## Reliability eval

Run from `daemon/`:

```powershell
npx tsx src/eval/cli.ts --corpus src/eval/corpora/core.json --k 3
npx tsx src/eval/cli.ts --corpus src/eval/corpora/holdout.json --k 3 --compare JARVIS_REFLECTION=1
```

Requires `ANTHROPIC_MODEL`, `ANTHROPIC_BASE_URL`, and `ANTHROPIC_AUTH_TOKEN` to point at a healthy gateway. See [Run a Reliability Eval](/docs/guides/run-reliability-eval).

## Database

Run from `daemon/`:

| Command | Description |
|---------|-------------|
| `pnpm db:generate` | Generate a migration and compile it |
| `pnpm db:migrate` | Apply migrations |
| `pnpm db:studio` | Open Drizzle Studio |
