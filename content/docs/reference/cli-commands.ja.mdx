title: CLIコマンド
description: CoreLayer リポジトリのパッケージスクリプトと補助コマンド。
---

CoreLayer は pnpm ワークスペースのスクリプトで動きます。特に断りのない限り、リポジトリルートで実行します。

## 開発

| コマンド | 説明 |
|----------|------|
| `pnpm dev` | デーモン + Tauri アプリを同時起動（concurrently） |
| `pnpm dev:daemon` | デーモンのみ。`tsx watch` でホットリロード |
| `pnpm dev:frontend` | Tauri アプリのみ |
| `pnpm dev:web` | ブラウザモードのフロントエンド（Tauri シェルなし） |

## ビルド

| コマンド | 説明 |
|----------|------|
| `pnpm build` | sidecar をビルドしてから Tauri アプリ |
| `pnpm build:daemon` | デーモンの TypeScript ビルド |
| `pnpm build:daemon:sidecar` | デーモンを sidecar 実行ファイル化 |

## 品質

| コマンド | 説明 |
|----------|------|
| `pnpm lint` / `pnpm lint:fix` | フロントエンド・デーモン・パッケージの ESLint |
| `pnpm format` / `pnpm format:check` | Prettier |
| `pnpm test` | 全パッケージの Vitest |
| `pnpm typecheck` | 全パッケージの TypeScript チェック |

`pnpm test` は信頼性評価を含みません。実際のモデル呼び出しを消費するため明示的に実行します（下記）。

## 検証とパッケージング

| コマンド | 説明 |
|----------|------|
| `pnpm test:smoke:sidecar` | ビルド済み sidecar のスモークテスト |
| `pnpm clean` | 全パッケージのビルド成果物を削除 |
| `pnpm clean:app` | 実行中のアプリプロセスを終了 |
| `pnpm clean:daemon` | 3001 番ポートを掴むプロセスを終了 |
| `pnpm clean:all` | 上記 2 つ |
| `pnpm clean:sea` | 単一実行ファイルビルドの一時ディレクトリを削除 |

## リリース

| コマンド | 説明 |
|----------|------|
| `pnpm release` | standard-version による patch リリース |
| `pnpm release:minor` | minor リリース |
| `pnpm release:major` | major リリース |
| `pnpm commitlint` | 直近のコミットメッセージを検証 |

## 信頼性評価

`daemon/` で実行：

```powershell
npx tsx src/eval/cli.ts --corpus src/eval/corpora/core.json --k 3
npx tsx src/eval/cli.ts --corpus src/eval/corpora/holdout.json --k 3 --compare JARVIS_REFLECTION=1
```

`ANTHROPIC_MODEL`、`ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN` を健全なゲートウェイに向ける必要があります。詳細は [信頼性評価の実行](/docs/guides/run-reliability-eval) を参照。

## データベース

`daemon/` で実行：

| コマンド | 説明 |
|----------|------|
| `pnpm db:generate` | マイグレーション生成とコンパイル |
| `pnpm db:migrate` | マイグレーション適用 |
| `pnpm db:studio` | Drizzle Studio を開く |
