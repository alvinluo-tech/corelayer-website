title: CLI 指令
description: CoreLayer 儲存庫中的套件腳本與輔助指令。
---

CoreLayer 由 pnpm workspace 腳本驅動。除特別說明外，指令均在儲存庫根目錄執行。

## 開發

| 指令 | 說明 |
|------|------|
| `pnpm dev` | 守護行程 + Tauri 應用同時啟動（concurrently） |
| `pnpm dev:daemon` | 僅守護行程，`tsx watch` 熱重載 |
| `pnpm dev:frontend` | 僅 Tauri 應用 |
| `pnpm dev:web` | 瀏覽器模式前端，不帶 Tauri 外殼 |

## 建置

| 指令 | 說明 |
|------|------|
| `pnpm build` | 先建置 sidecar，再建置 Tauri 應用 |
| `pnpm build:daemon` | 守護行程 TypeScript 建置 |
| `pnpm build:daemon:sidecar` | 將守護行程打包為 sidecar 可執行檔 |

## 品質

| 指令 | 說明 |
|------|------|
| `pnpm lint` / `pnpm lint:fix` | 覆蓋前端、守護行程與套件的 ESLint |
| `pnpm format` / `pnpm format:check` | Prettier |
| `pnpm test` | 所有套件的 Vitest |
| `pnpm typecheck` | 所有套件的 TypeScript 檢查 |

`pnpm test` 不包含可靠性評測——那會消耗真實模型呼叫，需要顯式執行（見下文）。

## 驗證與打包

| 指令 | 說明 |
|------|------|
| `pnpm test:smoke:sidecar` | 對建置好的 sidecar 做冒煙測試 |
| `pnpm clean` | 清理各套件建置產物 |
| `pnpm clean:app` | 結束正在執行的應用行程 |
| `pnpm clean:daemon` | 結束佔用 3001 連接埠的行程 |
| `pnpm clean:all` | 以上兩者 |
| `pnpm clean:sea` | 刪除單可執行檔建置的暫存目錄 |

## 發佈

| 指令 | 說明 |
|------|------|
| `pnpm release` | standard-version patch 發佈 |
| `pnpm release:minor` | minor 發佈 |
| `pnpm release:major` | major 發佈 |
| `pnpm commitlint` | 校驗最近一筆提交訊息 |

## 可靠性評測

在 `daemon/` 下執行：

```powershell
npx tsx src/eval/cli.ts --corpus src/eval/corpora/core.json --k 3
npx tsx src/eval/cli.ts --corpus src/eval/corpora/holdout.json --k 3 --compare JARVIS_REFLECTION=1
```

需要 `ANTHROPIC_MODEL`、`ANTHROPIC_BASE_URL` 與 `ANTHROPIC_AUTH_TOKEN` 指向健康的閘道。詳見 [執行可靠性評測](/docs/guides/run-reliability-eval)。

## 資料庫

在 `daemon/` 下執行：

| 指令 | 說明 |
|------|------|
| `pnpm db:generate` | 產生遷移並編譯 |
| `pnpm db:migrate` | 套用遷移 |
| `pnpm db:studio` | 開啟 Drizzle Studio |
