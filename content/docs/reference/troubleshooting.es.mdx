## La Aplicacion No Inicia

**Sintoma:** CoreLayer no se abre o falla inmediatamente.

**Soluciones:**
- Verifica que Node.js 22+ este instalado: `node --version`
- Verifica que pnpm 9+ este instalado: `pnpm --version`
- Revisa los prerrequisitos especificos de Tauri para tu plataforma
- Intenta recompilar: `pnpm clean && pnpm build`

## El Daemon No Inicia

**Sintoma:** "Daemon no saludable" o errores de conexion.

**Soluciones:**
- Verifica si el puerto 3001 esta en uso: `lsof -i :3001` (macOS/Linux) o `netstat -ano | findstr 3001` (Windows)
- Cierra los procesos en conflicto: `pnpm clean:daemon`
- Revisa los registros del daemon en el Centro de Control
- Verifica los permisos del archivo de base de datos

## El Modelo No Responde

**Sintoma:** Jarvis no responde o muestra "No model available".

**Soluciones:**
- Verifica que la clave API sea correcta en Ajustes → Modelos
- Revisa el estado del proveedor (Groq, OpenRouter, etc.)
- Prueba un modelo/proveedor diferente
- Verifica la conectividad de red

## El Servidor MCP No Se Conecta

**Sintoma:** El servidor muestra estado "Desconectado" o "Error".

**Soluciones:**
- Verifica que el comando y los argumentos sean correctos
- Prueba el comando manualmente en una terminal
- Verifica que npx pueda instalar el paquete: `npx -y @modelcontextprotocol/server-filesystem`
- Verifica que las variables de entorno esten configuradas
- Reinicia la conexion MCP desde el Centro de Control

## La Voz No Funciona

**Sintoma:** La palabra de activacion no se detecta o la voz no se reconoce.

**Soluciones:**
- Verifica los permisos del microfono en los ajustes del sistema
- Reduce el ruido de fondo
- Intenta hacer clic en el boton del microfono en lugar de usar la palabra de activacion
- Cambia el proveedor ASR a Groq Whisper para mayor precision
- Verifica los ajustes de salida de audio para TTS

## El Permission Guard Bloquea Todo

**Sintoma:** Todas las llamadas a herramientas requieren aprobacion.

**Soluciones:**
- `high` siempre requiere confirmacion y `critical` se deniega: es la politica por defecto, no un bug
- Usa "Recordar" en la aprobacion para no volver a preguntar por esa accion exacta
- Cierra solicitudes obsoletas con `POST /api/approvals/expire-stale`
- La politica aun no es configurable por el usuario; ver [Permisos](/docs/configuration/permissions)

## Una Aprobacion Parece Colgada

**Sintoma:** Una ejecucion nunca termina y no aparece ningun dialogo de aprobacion.

**Soluciones:**
- Consulta `GET /api/approvals` por una solicitud pendiente de esa ejecucion
- Las aprobaciones se persisten, asi que reiniciar el daemon no las pierde; tampoco las decide automaticamente
- Las confirmaciones inline de herramientas estan en `GET /api/tools/pending-confirmations`

## El Ejecutor de Codigo Falla de Inmediato

**Sintoma:** Una ejecucion de codigo falla antes de producir salida.

**Soluciones:**
- `GET /api/runtimes/coding/diagnostics` — revisa el estado de la sonda del agente
- `needs_auth` significa que el agente arranco pero no tiene credenciales; completa su login
- `unreachable` suele significar que `acpx` no esta instalado (`npm install acpx`) o que el comando de lanzamiento es incorrecto
- Claude Code solo corre modelos DeepSeek; un `ANTHROPIC_MODEL` que no sea DeepSeek se rechaza a proposito

## Los Intentos de Evaluacion Agotan el Tiempo

**Sintoma:** `pass^k` se desploma con muchos `timed-out`.

**Soluciones:**
- Revisa primero el gateway: un endpoint inestable hace que `acpx` se cuelgue hasta agotar el presupuesto en lugar de fallar rapido
- Los intentos `VOID` son fallos de entorno (cuota, conexion rechazada, 5xx) y se excluyen de las tasas
- Tres fallos de entorno seguidos detienen la evaluacion por diseno

## `POST /api/runs/:id/message` devuelve 410

Este endpoint se elimino con el bucle de agente escrito a mano. Usa la API estandar de envio de conversacion (`POST /api/conversations/:id/messages/stream`).

## Fallos de Compilacion

**Sintoma:** `pnpm build` falla.

**Soluciones:**
- Limpia y recompila: `pnpm clean && pnpm install && pnpm build`
- Verifica la cadena de herramientas de Rust: `rustc --version`, `cargo --version`
- Confirma los prerrequisitos de plataforma para Tauri
- Revisa errores de TypeScript: `pnpm typecheck`

## Problemas de Base de Datos

**Sintoma:** Los datos no se guardan o errores de carga.

**Soluciones:**
- Revisa el modo en `storage.json` (Ajustes → Almacenamiento lo escribe)
- Confirma que el archivo de base de datos exista y sea escribible bajo `storage/`
- Cambiar de modo requiere reiniciar el daemon; no es un hot-swap en vivo
- Para Supabase: verifica la URL del proyecto y la service key
