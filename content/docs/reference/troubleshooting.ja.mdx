## アプリが起動しない

**症状:** CoreLayerが起動しない、またはすぐにクラッシュする。

**解決策:**
- Node.js 22以上がインストールされているか確認: `node --version`
- pnpm 9以上がインストールされているか確認: `pnpm --version`
- プラットフォーム固有のTauri前提条件を確認
- リビルドを試す: `pnpm clean && pnpm build`

## デーモンが起動しない

**症状:** "Daemon unhealthy"または接続エラー。

**解決策:**
- ポート3001が使用されていないか確認: macOS/Linuxでは`lsof -i :3001`、Windowsでは`netstat -ano | findstr 3001`
- 競合プロセスを終了: `pnpm clean:daemon`
- コントロールセンターでデーモンログを確認
- データベースファイルの権限を確認

## モデルが応答しない

**症状:** Jarvisが応答しない、または"No model available"と表示される。

**解決策:**
- 設定 → モデルでAPIキーが正しいか確認
- プロバイダーのステータスを確認（Groq、OpenRouterなど）
- 別のモデル/プロバイダーを試す
- ネットワーク接続を確認

## MCPサーバーが接続されない

**症状:** サーバーが"Disconnected"または"Error"ステータスを表示。

**解決策:**
- コマンドとargsが正しいか確認
- ターミナルでコマンドを手動テスト
- npxがパッケージをインストールできるか確認: `npx -y @modelcontextprotocol/server-filesystem`
- 環境変数が設定されているか確認
- コントロールセンターからMCP接続を再起動

## 音声が動作しない

**症状:** ウェイクワードが検出されない、または音声が認識されない。

**解決策:**
- システム設定でマイクの権限を確認
- バックグラウンドノイズを軽減
- ウェイクワードの代わりにマイクボタンをクリックして試す
- より高い精度のためにASRプロバイダーをGroq Whisperに切り替え
- TTSのオーディオ出力設定を確認

## パーミッションガードがすべてをブロックする

**症状:** すべてのツール呼び出しに承認が必要。

**解決策:**
- `high` リスクは常に確認、`critical` は既定で拒否。これは既定ポリシーであり不具合ではない
- 承認で「記憶」を選べば同じアクションを二度尋ねない
- `POST /api/approvals/expire-stale` で古いリクエストを閉じる
- ポリシーはまだユーザー設定できません。[権限](/docs/configuration/permissions) を参照

## 承認が止まって見える

**症状:** 実行が終わらず、承認ダイアログも表示されない。

**解決策:**
- `GET /api/approvals` でその実行に保留中のリクエストがあるか確認
- 承認は永続化されるため再起動でも失われないが、自動決定もされない
- ツールのインライン確認は `GET /api/tools/pending-confirmations`

## コーディングエグゼキューターが即座に失敗する

**症状:** 出力を一切出さずにコーディング実行が失敗する。

**解決策:**
- `GET /api/runtimes/coding/diagnostics` でエージェントのプローブ状態を確認
- `needs_auth` はエージェントが起動したが資格情報がない状態。ログインを完了する
- `unreachable` は通常 `acpx` 未インストール（`npm install acpx`）か起動コマンドの誤り
- Claude Code は DeepSeek モデルのみ。DeepSeek でない `ANTHROPIC_MODEL` は意図的に拒否される

## 評価の試行がタイムアウトする

**症状:** `pass^k` が崩れ、`timed-out` が多い。

**解決策:**
- まずゲートウェイを確認。不安定なエンドポイントでは `acpx` が実行予算まで固まり、失敗せずに待ち続ける
- `VOID` 試行は環境障害（クォータ、接続拒否、5xx）で、比率から除外される
- 環境障害が 3 回連続すると、設計どおり評価全体を停止する

## `POST /api/runs/:id/message` が 410 を返す

このエンドポイントは手書きエージェントループの廃止とともに削除されました。標準の会話送信 API（`POST /api/conversations/:id/messages/stream`）を使ってください。

## ビルド失敗

**症状:** `pnpm build`が失敗する。

**解決策:**
- クリーンしてリビルド: `pnpm clean && pnpm install && pnpm build`
- Rustツールチェーンを確認: `rustc --version`、`cargo --version`
- Tauriのプラットフォーム前提条件を確認
- TypeScriptエラーを確認: `pnpm typecheck`

## データベースの問題

**症状:** データが保存されない、または読み込みエラー。

**解決策:**
- `storage.json` のストレージモードを確認（設定 → ストレージ が書き込む）
- `storage/` 配下のデータベースファイルが存在し書き込み可能か確認
- ストレージモードの切り替えはデーモン再起動が必要。ライブなホットスワップではない
- Supabase の場合: プロジェクト URL とサービスキーを確認

## まだ解決しない場合？

- 既知の問題については[GitHub Issues](https://github.com/alvinluo-tech/CoreLayer/issues)を確認
- 新しいissueを作成:
  - お使いのプラットフォームとバージョン
  - 再現手順
  - エラーメッセージまたはログ
  - 期待される動作と実際の動作
