title: Comandos CLI

---

CoreLayer se maneja con scripts del workspace de pnpm. Todos los comandos se ejecutan desde la raiz del repositorio salvo que se indique otra cosa.

## Desarrollo

| Comando | Descripcion |
|---------|-------------|
| `pnpm dev` | Daemon + app Tauri a la vez (concurrently) |
| `pnpm dev:daemon` | Solo el daemon, con `tsx watch` |
| `pnpm dev:frontend` | Solo la app Tauri |
| `pnpm dev:web` | Frontend en navegador, sin shell de Tauri |

## Compilacion

| Comando | Descripcion |
|---------|-------------|
| `pnpm build` | Sidecar, luego la app Tauri |
| `pnpm build:daemon` | Build TypeScript del daemon |
| `pnpm build:daemon:sidecar` | Empaquetar el daemon como ejecutable sidecar |

## Calidad

| Comando | Descripcion |
|---------|-------------|
| `pnpm lint` / `pnpm lint:fix` | ESLint en frontend, daemon y paquetes |
| `pnpm format` / `pnpm format:check` | Prettier |
| `pnpm test` | Vitest en todos los paquetes |
| `pnpm typecheck` | TypeScript en todos los paquetes |

`pnpm test` no ejecuta la evaluacion de fiabilidad: cuesta turnos reales de modelo y se invoca explicitamente (ver abajo).

## Verificacion y empaquetado

| Comando | Descripcion |
|---------|-------------|
| `pnpm test:smoke:sidecar` | Smoke test del sidecar compilado |
| `pnpm clean` | Limpiar salidas de build de todos los paquetes |
| `pnpm clean:app` | Matar un proceso de la app en ejecucion |
| `pnpm clean:daemon` | Matar lo que ocupa el puerto 3001 |
| `pnpm clean:all` | Ambos |
| `pnpm clean:sea` | Borrar el directorio temporal del build ejecutable unico |

## Release

| Comando | Descripcion |
|---------|-------------|
| `pnpm release` | Release patch con standard-version |
| `pnpm release:minor` | Release minor |
| `pnpm release:major` | Release major |
| `pnpm commitlint` | Validar el ultimo mensaje de commit |

## Evaluacion de fiabilidad

Ejecutar desde `daemon/`:

```powershell
npx tsx src/eval/cli.ts --corpus src/eval/corpora/core.json --k 3
npx tsx src/eval/cli.ts --corpus src/eval/corpora/holdout.json --k 3 --compare JARVIS_REFLECTION=1
```

Requiere `ANTHROPIC_MODEL`, `ANTHROPIC_BASE_URL` y `ANTHROPIC_AUTH_TOKEN` apuntando a un gateway sano. Ver [Ejecutar una Evaluacion](/docs/guides/run-reliability-eval).

## Base de datos

Ejecutar desde `daemon/`:

| Comando | Descripcion |
|---------|-------------|
| `pnpm db:generate` | Generar una migracion y compilarla |
| `pnpm db:migrate` | Aplicar migraciones |
| `pnpm db:studio` | Abrir Drizzle Studio |
