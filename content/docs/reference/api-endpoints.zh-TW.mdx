title: API 端點參考

---

守護行程暴露回環 HTTP API（預設 `127.0.0.1:3001`，可用 `DAEMON_HOST` / `DAEMON_PORT` 覆寫）。Tauri 介面經外殼代理存取它；工具和腳本可在同一台機器上直接呼叫。

回應為 JSON。按路由不同，集合的包裝形式為 `{ "data": [...] }` 或 `{ "entries": [...], "total": n, "count": n }`。

## 健康與執行階段

| 方法 | 路徑 | 用途 |
|------|------|------|
| GET | `/api/health`、`/health` | `{ status, timestamp, storageMode, aiProvider, aiModel }` |
| GET | `/api/runtime/status` | pid、執行時長、記憶體、儲存模式、路徑、各執行階段健康 |
| GET | `/api/runtime/components` | 已註冊執行階段元件與狀態 |
| POST | `/api/runtime/shutdown` | 停止守護行程（僅回環對端） |
| GET | `/api/runtime/queue` · `/status` · `/resources` | 佇列深度、槽位狀態、資源用量 |
| GET | `/api/runtimes/coding/diagnostics` | 編碼執行器診斷 |
| POST | `/api/runtimes/coding/:id/dry-run` | 執行器試執行 |

## 核准

| 方法 | 路徑 | 用途 |
|------|------|------|
| GET | `/api/approvals` | 待定與最近 |
| GET | `/api/approvals/:id` | 單一請求 |
| POST | `/api/approvals/:id/approve` | 核准並恢復 |
| POST | `/api/approvals/:id/deny` | 拒絕並終止執行 |
| POST | `/api/approvals/:id/remember` | 核准並寫入權限記憶 |
| POST | `/api/approvals/batch/approve` · `/batch/deny` | 批次決定 |

## 鑑權

不需要 token：API 綁定在回環位址，不暴露到網路。`/api/runtime/shutdown` 還會校驗對端位址是回環。
