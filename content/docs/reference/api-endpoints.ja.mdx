---
title: APIエンドポイントリファレンス
description: デーモン HTTP API。リソースごとに整理。
---

デーモンはループバック HTTP API（既定 `127.0.0.1:3001`、`DAEMON_HOST` / `DAEMON_PORT` で変更可）を公開します。Tauri UI はシェルプロキシ経由で到達し、ツールやスクリプトは同一マシンから直接呼べます。

レスポンスは JSON です。ルートによってコレクションは `{ "data": [...] }` または `{ "entries": [...], "total": n, "count": n }` で包まれます。

## ヘルスとランタイム

| メソッド | パス | 用途 |
|---------|------|------|
| GET | `/api/health`、`/health` | `{ status, timestamp, storageMode, aiProvider, aiModel }` |
| GET | `/api/runtime/status` | pid、稼働時間、メモリ、ストレージモード、パス、ランタイム別の健康 |
| GET | `/api/runtime/components` | 登録済みランタイムの構成と状態 |
| POST | `/api/runtime/shutdown` | デーモン停止（ループバックのピアのみ） |
| GET | `/api/runtime/queue` · `/status` · `/resources` | キューの深さ、スロット状態、リソース使用量 |
| GET | `/api/runtimes/coding/diagnostics` | コーディングエグゼキューター診断 |
| POST | `/api/runtimes/coding/:id/dry-run` | エグゼキューターのドライラン |

## 承認

| メソッド | パス | 用途 |
|---------|------|------|
| GET | `/api/approvals` | 保留中と最近 |
| GET | `/api/approvals/:id` | 単一リクエスト |
| POST | `/api/approvals/:id/approve` | 承認して再開 |
| POST | `/api/approvals/:id/deny` | 拒否して実行を失敗させる |
| POST | `/api/approvals/:id/remember` | 承認して権限メモリを保存 |
| POST | `/api/approvals/batch/approve` · `/batch/deny` | 一括決定 |
| POST | `/api/approvals/expire-stale` | 未応答リクエストの締め処理 |

`/api/permissions/*` グループは存在しません。承認と監査は別リソースです。

## 認証

トークンは不要です。API はループバックにバインドされ、ネットワークに公開されません。`/api/runtime/shutdown` はさらにピアアドレスがループバックであることを確認します。
