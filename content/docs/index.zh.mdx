## 什么是 CoreLayer？

CoreLayer 位于你与个人应用生态之间。它不是困在浏览器标签页里的聊天机器人，而是桌面控制层：

- **执行系统而非聊天记录** — 目标 → 工作空间 → 任务图 → 运行实例 → 可验证产物
- **执行器治理** — Claude Code、Codex、OpenCode 被收拢为受管执行器，隔离在 git worktree 中
- **权限优先** — 四个风险等级、可跨重启保留的审批、完整审计
- **MCP 优先** — 原生支持 stdio、HTTP 与 SSE，工具统一注册并标注风险
- **语音原生** — 唤醒词、流式 ASR/TTS、打断续听
- **本地优先** — 六分区磁盘布局，默认 SQLite，可选 Supabase / PostgreSQL
